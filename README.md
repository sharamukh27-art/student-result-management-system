A menu-driven C program to manage student records with file persistence, analytics, color output, and professional report generation.

## Features

### Core CRUD
- Add Student — duplicate roll check, marks validation (0–100), roll validation (1–9999)
- Display All Students — color-coded report cards with rank and timestamp
- Search — by Roll Number or by Name (case-insensitive partial match)
- Update — name, marks, or both
- Delete — with confirmation prompt

### Analytics
- Subject Toppers — highest scorer and class average per subject
- Grade Distribution — count of A / B / C / D / F grades
- Class Statistics — highest, lowest, average percentage; pass/fail counts
- Merit List — all students ranked by percentage in a table

### Sorting
- By Name (alphabetical)
- By Roll Number
- By Percentage (highest first)

### File Handling
- Auto-save to `students.dat` on every change
- Auto-load on startup — data is never lost
- File version guard — detects and discards stale/incompatible data files automatically
- Export full report to `report.txt` with timestamp
- Backup to `backup_DD_MM_YYYY.dat`

### Input Validation
- Marks: 0–100 (re-prompts on invalid input)
- Roll number: 1–9999, unique
- Name: non-empty, must contain letters
- Menu choice: validated — no crashes on bad input

### Polish
- ANSI color output — green (pass/success), red (fail/error), yellow (warning), blue (UI)
- Box-drawn report cards with rank, timestamp, division label
- Startup banner with version number
- Help screen and About screen
- Timestamp recorded when each student is added

## How to Compile and Run

**Requirement:** GCC (macOS: install via `xcode-select --install`)

```bash
# Compile
gcc -Wall -Wextra -o result main.c student.c

# Run
./result
```
